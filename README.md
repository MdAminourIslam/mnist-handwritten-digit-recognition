# MNIST Handwritten Digit Recognition

A simple handwritten digit recognition project using Convolutional Neural Networks (CNN) and TensorFlow with the MNIST dataset.

## Technologies
- Python
- TensorFlow & Keras
- NumPy
- Matplotlib
- OpenCV
- Google Colab

## Features
- MNIST dataset loading and preprocessing
- CNN model building and training
- Model evaluation and accuracy visualization
- Confusion matrix
- Handwritten digit prediction

## Notebook

**MNIST Handwritten Digit Recognition.ipynb**

The notebook contains the complete implementation, from data preprocessing and CNN training to handwritten digit prediction.
